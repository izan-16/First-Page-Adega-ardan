Descripción

Este es mi primer proyecto de desarrollo web realizado exclusivamente con html y css, en el cual he usado de referencia la pagina web de Adega Ardan.
Ha sido un proyecto muy interesante a la par que entretenido y me siento orgulloso del trabajo que he echo.
La pagina esta compuesta por un header bonito y elegante en el cual se ve de fondo la maravillosa ribeira sacra uno de los muchos sitios inpresionantes
que tiene Galicia, incluye un main con una breve descripción de lo que se dedica la bodega, también incluye una galería de imágenes para apreciar las increíbles 
viñas y paisajes, concluyendo con una breve descripción de uno de los vinos mas populares el "Praia do santo" inspirado en una de las playas mas emblemáticas de Marín que es el pueblo de origen
y por ultimo pero no menos importante el footer o pie de pagina con una breve descricipon.
